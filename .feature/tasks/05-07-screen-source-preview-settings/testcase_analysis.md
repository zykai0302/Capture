# Requirements Analysis Report: 画面源预览与设置面板折叠

## 1. Project Background

### Current Issues
- 左侧画面源列表中，显示器和窗口数量过多时显示不全，无法滚动查看
- 画面源（显示器/窗口）只显示 SVG 占位图，无法预览真实画面内容
- 推流中的画面源，中央区域显示 SVG 模拟画面，无法看到推流实时画面
- 右侧设置面板始终占据空间，无法折叠以获得更大的预览区域

### Project Goals
优化主界面三大区域的交互体验：左侧支持滚动+缩略图预览、中间实时显示推流画面、右侧设置面板可折叠

## 2. Requirements Overview

### Core Objective
画面源列表支持滚动浏览和缩略图自动刷新、推流画面按编码帧率实时显示、设置面板可折叠/展开

### Applicable Scenarios
- 用户有多个显示器和多个窗口，需要在列表中浏览和选择
- 用户想预览画面源的实际内容以快速识别目标源
- 用户在推流时希望实时查看推流效果
- 用户需要更大的推流画面预览区域，暂时不需要调整设置

### Core Features

| Feature | Description |
|---------|-------------|
| 画面源列表滚动 | 当源列表超出可视区域时，可滚动浏览所有源 |
| 画面源缩略图预览 | 每个源显示真实截图缩略图，每5秒自动刷新 |
| 推流画面实时显示 | 推流中的源在中央区域按编码帧率实时显示画面 |
| 设置面板折叠 | 点击设置按钮切换右侧面板显示/隐藏，折叠后推流区域变大 |

## 3. Functional Requirements

### 画面源列表滚动
- **Interaction Logic**: 用户在左侧面板上下滚动浏览画面源
- **Operation Path**: 左侧面板 → 画面源列表区域
- **Expected Result**: 当源数量超出可视区域时，出现滚动条，可流畅上下滚动

### 画面源缩略图预览
- **Interaction Logic**: 系统自动截取每个画面源的当前画面作为缩略图
- **Operation Path**: 左侧面板 → 画面源卡片中的预览区域
- **Expected Result**: 显示器源显示桌面截图，窗口源显示窗口截图，截图失败时显示占位图

### 推流画面实时显示
- **Interaction Logic**: 选中正在推流的画面源后，中央区域自动显示推流实时画面
- **Operation Path**: 选中推流中的源 → 中央预览区域
- **Expected Result**: 中央区域显示与编码帧率一致的实时画面，停止推流后画面消失

### 设置面板折叠
- **Interaction Logic**: 点击顶栏右侧的设置按钮，切换右侧面板显示/隐藏
- **Operation Path**: 顶栏 → 设置按钮 → 右侧面板
- **Expected Result**: 点击后面板隐藏/显示，推流区域相应变大/恢复，过渡动画平滑

## 4. Functional Specifications

| Configuration | Limit | Notes |
|---------------|-------|-------|
| 缩略图尺寸 | 320x180 像素 | JPEG 格式，质量60 |
| 缩略图刷新间隔 | 5 秒 | 与源列表刷新同步 |
| MJPEG 预览帧率 | 等于编码帧率 | 默认30fps |
| MJPEG 服务端口 | 默认8090 | 可配置 |
| 设置面板宽度 | 340px | 折叠时为0px |
| 过渡动画时长 | 0.3秒 | CSS ease 缓动 |

## 5. Business Design

1. 用户打开应用，左侧显示画面源列表，每个源显示真实缩略图
2. 系统每5秒自动刷新所有源的缩略图
3. 用户选择一个画面源，点击开始推流
4. 推流开始后，中央区域自动显示推流实时画面（帧率=编码帧率）
5. 用户点击设置按钮，右侧面板折叠，中央预览区域自动扩展
6. 用户再次点击设置按钮，右侧面板展开，布局恢复
7. 用户停止推流，中央预览画面自动消失，显示占位提示

## 6. Human-Interface Changes

- 画面源卡片中的 SVG 占位图 → 真实截图缩略图
- 中央区域推流状态下的 SVG 模拟画面 → MJPEG 实时流画面
- 顶栏设置按钮：从无功能 → 点击切换右侧面板
- 右侧面板：从始终显示 → 可折叠/展开
- 中央区域：宽度从固定 → 随面板折叠动态扩展

## 7. Technical Requirements

- 缩略图截图延迟 < 500ms（单次）
- 推流画面延迟 < 100ms（MJPEG 本地流）
- 折叠/展开过渡动画流畅（60fps）
- 应用内存无泄漏（缩略图 URL 正确释放）
- 推流功能不受预览影响（独立 pipeline）

## 8. Product Type

**Product Type**: 桌面推流软件（非标准分类）
**Checklist**: 无（基于 PRD 验收标准直接设计）

## 9. Risks and Constraints

- 窗口最小化时截图可能返回黑屏（需 fallback 到占位图）
- 双重画面捕获（推流+预览）可能增加 CPU/GPU 开销
- 同一画面源仅支持一个 MJPEG 客户端连接
- CSS Grid 列过渡动画需要 Chrome 107+ 浏览器
- 仅支持 Windows 平台截图
